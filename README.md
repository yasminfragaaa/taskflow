
# TaskFlow — Task Management App

TaskFlow is a responsive task management application built with HTML, CSS, and JavaScript.

The project was developed to practice front-end development, DOM manipulation, and JavaScript fundamentals.

## Features

- Create, edit, and delete tasks
- Mark tasks as completed
- Organize tasks by category
- Filter tasks by status
- Sort tasks by date, priority, or name
- Save tasks using LocalStorage
- Responsive interface

## Technologies Used

- HTML5 — Page structure
- CSS3 — Styling and responsive layout
- JavaScript — Application logic and interactivity
- LocalStorage — Browser data persistence

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start organizing your tasks!
